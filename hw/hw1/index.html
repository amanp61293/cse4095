Recursive Idea

Every black checker must eventually occupy an odd-numbered position: 1, 3, 5, and so on.

The recursive function finds the next black checker, moves it left using adjacent swaps, and then recursively solves the next target position. 

def checker_swap(checkers, target_index=1):

    # Base case
    if target_index >= len(checkers):
        return

    # Find the next black checker
    black_index = target_index

    while (black_index < len(checkers)
           and checkers[black_index] != 1):

        black_index += 1

    # Move it left using adjacent swaps
    while black_index > target_index:

        checkers[black_index], checkers[black_index - 1] = \
            checkers[black_index - 1], checkers[black_index]

        black_index -= 1

    # Recursive call
    checker_swap(checkers, target_index + 2)
